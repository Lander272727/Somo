🔩 Hardware · Taller 1

Montaje de Componentes

¿Qué aprenderás?

En este taller partimos de cero: identificamos cada pieza de un ordenador, entendemos para qué sirve y la montamos con nuestras propias manos.

Desde el chasis hasta el primer arranque del sistema operativo: colocación correcta de la CPU, pasta térmica, módulos de RAM en modo dual-channel, tarjeta gráfica y discos SSD/NVMe. También aprendemos a leer el manual de la placa base y a interpretar los códigos POST cuando algo falla.

Al terminar serás capaz de montar un equipo desde piezas sueltas, diagnosticar averías básicas y recomendar componentes según presupuesto y uso.

Duración6 semanas
Modalidad100 % práctica en taller físico
EvaluaciónPC funcionando + informe técnico
🎯 Reto Ethazi
Montar un PC funcional desde piezas sueltas, instalar el sistema operativo (Windows 11 o Ubuntu) y entregar un informe técnico con foto y diagnóstico de cada componente. ¡El PC que montes es el que usarás el resto del trimestre!

El reto se trabaja en equipos de 2 personas. Cada equipo recibe una caja con todas las piezas y tiene que organizarse para montar, configurar y documentar el proceso completo en un plazo de 3 sesiones de taller.

La presentación final es oral: explicáis cada decisión de montaje al resto de la clase y respondéis preguntas. Aprendes a defender tu trabajo.

EquiposParejas (2 personas)
Plazo3 sesiones de taller
PresentaciónOral + demostración en vivo
🛠 Herramientas y materiales

Todo el material lo facilita el centro. Esto es con lo que trabajamos:

  • Destornilladores de precisión
  • Pasta térmica
  • Pulsera antiestática
  • Multímetro
  • POST card diagnóstico
  • Windows 11
  • Ubuntu 24 LTS
  • CPU-Z
  • HWiNFO64
  • CrystalDiskInfo
  • MemTest86

También usamos software de diagnóstico para comprobar que cada componente funciona correctamente antes de dar el reto por completado.

📊 Nivel del reto
Dificultad general70 %
Trabajo en equipo85 %
Documentación60 %

Este taller está pensado para quien no ha tocado nunca un PC por dentro. No hace falta experiencia previa: el profesorado guía cada paso.

PrerequisitosNinguno
Nota mínimaPC arrancando + informe entregado
📡 Redes · Taller 2

Redes Locales

¿Qué aprenderás?

Aprenderemos a diseñar e implementar una red de área local (LAN) desde cero. Crimpamos nuestros propios cables RJ-45 (Cat5e y Cat6) y comprobamos su continuidad con un tester.

Configuramos switches no gestionados, asignamos direcciones IP de forma estática y automática (DHCP) y diagnosticamos fallos de conectividad usando herramientas de línea de comandos: ping, tracert, ipconfig y nslookup.

Al terminar sabrás montar una red de oficina pequeña, detectar problemas de conectividad y documentar la topología de la red.

Duración5 semanas
ModalidadPráctica en taller + simulador
EvaluaciónRed funcionando + mapa documentado
🎯 Reto Ethazi
Montar una red funcional para el aula con al menos 10 dispositivos, segmentada en dos grupos (alumnado y profesorado), con acceso a internet y mapa de red documentado. Si la red cae durante la evaluación, la levantáis en vivo.

El equipo completo es responsable de que la red funcione el día de la presentación. Se evalúa tanto la parte técnica como la capacidad de explicar las decisiones de diseño: ¿por qué ese esquema de IPs? ¿por qué ese switch en ese punto?

EquiposGrupos de 3-4 personas
Plazo4 sesiones de taller
PresentaciónDemostración en directo
🛠 Herramientas y materiales

Combinamos hardware real con simuladores para afianzar conceptos:

  • Crimpeadora RJ-45
  • Cable UTP Cat5e / Cat6
  • Tester de red
  • Switch Cisco / TP-Link
  • Router doméstico
  • ping · tracert
  • ipconfig · nslookup
  • Wireshark
  • Cisco Packet Tracer

Wireshark nos permite ver en tiempo real qué paquetes viajan por la red y detectar problemas de forma visual. ¡Es como tener rayos X para los datos!

📊 Nivel del reto
Dificultad general60 %
Diagnóstico de fallos75 %
Documentación de red65 %

El mayor reto no es técnico sino organizativo: coordinar al equipo para que todos sepan qué cable van a crimpar y por qué va a ese puerto.

PrerequisitosTaller de Montaje completado
Nota mínimaRed activa + mapa entregado
🌐 Desarrollo Web · Taller 3

Creación de Webs

¿Qué aprenderás?

Empezamos con HTML semántico para estructurar contenido correctamente (cabeceras, listas, formularios, tablas), pasamos a CSS para diseñar páginas responsive que se vean bien en móvil y en escritorio, y terminamos con JavaScript para añadir interactividad real.

Formularios con validación, menús de navegación, contadores en tiempo real, animaciones de scroll… todo lo que ves en esta misma página es el resultado de lo que aprendemos en clase.

Al terminar tendrás publicado tu propio portfolio en internet, visible desde cualquier dispositivo del mundo.

Duración8 semanas
ModalidadPráctica en aula + publicación online
EvaluaciónPortfolio publicado + defensa oral
🎯 Reto Ethazi
Crear y publicar tu portfolio personal en GitHub Pages. Debe incluir una página de presentación, un listado de proyectos con capturas y un formulario de contacto. Se presenta en vivo al resto de la clase: defiendes tu web y explicas cada decisión de diseño.

Este reto es individual: tu web, tu nombre, tu identidad digital. El objetivo es que al salir del módulo tengas algo real que mostrar en una entrevista de trabajo o prácticas.

El profesor y los compañeros dan feedback en tiempo real durante la presentación. Aprenderás tanto de tus errores como de los de los demás.

EquiposIndividual
Plazo6 sesiones de desarrollo
PresentaciónDefensa oral + URL publicada
🛠 Herramientas y materiales

Tecnologías estándar del sector, sin frameworks ni librerías — solo la base:

  • HTML5 semántico
  • CSS3
  • Flexbox
  • CSS Grid
  • JavaScript ES6+
  • VS Code
  • Git
  • GitHub Pages
  • Chrome DevTools
  • Lighthouse
  • Can I use

Lighthouse nos da una puntuación de rendimiento, accesibilidad y SEO. El objetivo es llegar a 90+ en todas las categorías antes de la entrega.

📊 Nivel del reto
Dificultad general55 %
Diseño responsive70 %
JavaScript interactivo65 %

El mayor reto es el diseño: que algo funcione es fácil, que además se vea bien en un móvil de 360 px ya requiere más cabeza.

PrerequisitosNinguno
Nota mínimaURL activa + código en GitHub
